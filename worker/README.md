# Сервер бота «Что пьём?»

Cloudflare Worker `whattodrinkuh-stars`. Сейчас код в Cloudflare вставлен вручную (минифицированная копия этого файла, esbuild --minify-whitespace); автодеплой из GitHub не подключён — у приложения Cloudflare нет доступа к репозиторию.

- `/setup` — вебхук, команды бота (`?links=1` — заново создать ссылки на оплату звёздами).
- `/hook` — обновления Telegram: кнопки, поиск рецептов, inline-режим, голосования в группах, оплата звёздами.
- `/api/*` — для приложения (подпись initData): напоминания по настойкам, общие списки, черновики голосований.
- Cron каждые 30 минут — рассылка напоминаний.

Секрет `BOT_TOKEN` — только в Cloudflare. Хранилище — KV `whattodrinkuh`.
